# 无聊宇宙 V3.0

一个收集奇怪念头、陪人发呆的中文游乐场。首页的「你好」「无聊」和聊绒都可以直接互动。每日推荐按浏览器本地日期更新，也可以换一组或恢复当天的默认推荐。

## 本地运行

使用 Node.js 24。

```sh
npm ci
npm run check
npm test
npm run dev
```

打开 http://localhost:3000。生产站点使用同一套路由与静态资源。

| 路由 | 内容 |
| --- | --- |
| `/` | 聊绒初次见面、首页互动计数、每日推荐和隐藏发现进度 |
| `/little-worlds` | 奇怪小站集合，进入四个独立互动世界 |
| `/little-worlds/cloud-gate` | 画笔迹打开三种房间，也可跳过绘画直接开门 |
| `/little-worlds/asteroid` | 60 秒单人探索，用键盘、方向按钮或点选目标找星星 |
| `/little-worlds/comic` | 阅读《聊绒和失踪的星期一》，探索七个分镜与两个结局 |
| `/little-worlds/shape-lab` | 摆放八类形状，保存、恢复单份作品或导出 PNG |
| `/random` | 随机体验，也可直接打开 `/random?id=catch`、`/random?id=potato`、`/random?id=door` 或 `/random?id=fish` |
| `/lab` | 按钮里程碑、证书和精选实验 |
| `/space-daze` | 拖动、收藏星星，布置星球，为月亮换装，以及手动开启的环境音 |
| `/fortune` | 30 个命运任务，按类型抽取、完成和分享 |
| `/collection` | 分类、排序和内容收藏 |
| `/archive` | 活跃时长、游戏成绩、收藏、隐藏发现、引导进度与聊绒的念头罐 |

在星空可以拖动星星，也可以给星星聚焦后用方向键移动。点击星星或按回车、空格，可以收藏或放回。抓聊绒支持触屏和键盘。金鱼投篮可以按时机投球，或移动力度滑块手动瞄准。手动瞄准偏好会记住。网页或系统开启减少动画时会使用手动瞄准，系统偏好与手动选择分别管理。设置位于桌面页眉或手机导航菜单。

## 奇怪小站

首页和奇怪合集都可以进入小站。集合与独立地址支持直接访问和刷新。各小站有自己的玩法与视觉场景，共用聊绒、收藏、返回入口和操作帮助。

小站元数据在 `public/microsites/catalog.js`，入口、公共外壳和按需加载在 `public/microsites.js`。四个互动模块各自渲染界面，由路由挂载，并通过 AbortSignal 清理事件和动画循环。绘画与形状使用 Canvas 2D，小行星使用 DOM 与单个动画循环，漫画按分镜数据选择下一格。

新增小站时，先在目录定义体验，再增加独立模块及加载器。漫画可从 `public/microsites/comic.js` 的分镜数据扩展。研究来源与原创取舍见 [奇怪小站的交互研究](docs/awwwards-inspiration-research.md)。

完整的功能、存档字段和验证范围见 [V3.0 开发报告](docs/v3-development-report.md)。

## 内容和存档

体验、剧情、任务、发现和每日推荐在 `public/content.js` 中管理。上新顺序来自体验目录的加入顺序。命运分享链接使用任务数组下标，新任务应追加到末尾。打开或刷新分享链接会开启对应任务的一次新尝试，在分配局抽到的任务会通过本地存档恢复。小游戏控制器在 `public/games.js`，聊绒的状态和对话在 `public/mascot.js`，页面渲染与导航在 `public/app.js`。

存档仍使用 `wuliao-universe-v1`。升级时验证各字段，保留原有计数、收藏和装扮，并从可证明的旧计数恢复已达成的彩蛋。V2.1 新增的 `homeCounters`、`tipsSeen` 和 `settings.fishManual` 也通过同一个迁移入口校验。首页计数从升级后开始累计，原有彩蛋保留；只有旧计数、缺少时间的彩蛋会标记为旧版记录。V2 活跃时长从升级后开始计量，仅在页面可见且最近 60 秒有交互时累积。实验室提示音默认关闭，开启后会记住选择。环境音需在宇宙页主动开启，离开时停止。

V3.0 在同一个存档中加入 `microsites`，保存各小站到访与完成次数、秘密和发现时间、云朵房间、小行星最佳星数与用时、漫画结局和上次保存的图形布局。小行星按星数优先、用时其次比较。图形布局最多保存 40 个元素；清空画布和重新开始都可用「恢复上次作品」找回已保存内容。旧档案字段继续通过原有规则校验。

插画与字体在 `public/assets/`，字体许可见 `licenses/`。本地测试覆盖存档迁移、计时、每日推荐、原有互动记录，以及小站独立地址、房间选择、星数排名、漫画分支和图形布局校验。

## Cloudflare

`wrangler.jsonc` 将静态资源发布为 Cloudflare Worker，并给子域名 `wuliao.tianyuanai.top` 配置自定义域。部署账号需要能管理该 Worker 和 `tianyuanai.top` 区域。

```sh
npx wrangler login --device
npm run deploy
```
