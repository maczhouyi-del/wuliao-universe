# 奇怪小站的交互研究

访问了参考站的公开网页及相关案例。交互浏览器在本次会话中未能启动，所以下面的观察来自可读取的页面、作品截图、元素演示目录和创作者说明。实时按键手感、完整剧情和跨设备表现没有经过实玩验证。技术一栏区分公开披露的工具和本项目的实现方案。

## Why Zero

- **作品与流程** · Awwwards 将它描述为 Zero University 的沉浸式介绍。作品元素目录分别展示页面解锁、长按继续、滚动叙事、可操作地图和定制折纸表单。由这些片段可以确认它将进入、转场和探索拆成不同动作，但目录未给出完整操作顺序。
- **视觉与技术** · 白色和鲜绿贯穿界面，排版、地图和着色器构成叙事层次。案例标注 Three.js、GSAP 和 Blender。
- **取舍与原创改造** · 云朵之门只借鉴「用户的第一笔会改变世界」。用 Canvas 2D 测量笔迹长度，CSS 展开原创小门。门后是三间无聊宇宙的房间，并提供键盘可用的直接开门入口。城市地图、品牌、绘制零和破裂转场不进入本项目。实现复杂度中等，主要工作是规范触屏坐标与重置状态。

[官方网站](https://why.zero.university/) · [Awwwards 作品与交互元素](https://www.awwwards.com/sites/why-zero)

## Ponpon Mania

- **作品与流程** · Justine Soulié 和 Patrick Heng 创作的互动漫画。公开入口提供「开始阅读」、章节和双语切换。作者的作品页通过封面、插画和技术标签说明角色表演与动画是作品的一部分。
- **视觉与技术** · 公开图像呈现海报式开场和鲜明的角色插画。作者标注 WebGL、GLSL、JavaScript。各章节的具体过场与分支未经实玩验证。
- **取舍与原创改造** · 聊绒漫画屋采用可点击的分镜和可重读的章节，配合分支选择。故事、对话和构图全部原创，采用项目既有聊绒、土豆、月亮与 CSS 拼贴。实现复杂度中等，内容和分支状态比动画实现耗时。

[官方网站](https://ponpon-mania.com/) · [创作者介绍](https://ponpon-mania.com/about) · [Patrick Heng 作品页](https://okaydev.co/u/pat_hg/portfolio/ponpon-mania)

## Messenger

- **作品与流程** · abeto 的小型行星探索体验。案例围绕进入一个奇异的空间、移动、与场景或其他参与者建立联系展开。地标给用户理由偏离最短路线。具体任务触发次序未实测。
- **视觉与技术** · 案例图展示墨线式空间和克制的几何地貌。公开作品页和技术展台指向 WebGL/WebGPU 的实时场景。
- **取舍与原创改造** · 聊绒的小行星围绕找三颗星和阅读地标展开，树、房子和门承担线索。用二维坐标、DOM 和单一动画循环实现单人探索，舍弃同步、聊天和三维相机。实现复杂度中高，重点是暂停、计时和键盘与触屏的一致性。

[官方网站](https://messenger.abeto.co/) · [Awwwards 案例](https://www.awwwards.com/messenger.html) · [WebGPU 展台](https://webgpu.com/showcase/messenger/)

## Grids

- **作品与流程** · Obys 的设计教育项目，用列网格、Van de Graaf、矩形网格和特殊构图解释排版。从章节进入例子，再阅读边距、间距和排版规则。公开内容没有证明原站允许自由拖动元素。
- **视觉与技术** · 大字号、网格线和图文的尺度对照让规则本身可见。项目的具体前端栈未核实。布局实验在本站用 CSS 网格和 Canvas 足以实现。
- **取舍与原创改造** · 形状实验室借用可见网格与即时构图反馈，加入独立的自由拖动、旋转、随机排列和作品保存。保持网格是低对比参考线，避免教程段落和强制对齐压过创作。实现复杂度中高，重点是触屏拖动与绘图一致性。

[官方网站](https://grids.obys.agency/) · [Obys 项目页](https://obys.agency/work/grids)

## Bruno Simon

- **作品与流程** · 用驾驶探索作品集。官方页面列出键盘、触屏、手柄、交互、地图、脱困、重置和成就。空间本身就是导航。实时驾驶没有经过实玩验证。
- **视觉与技术** · 公开图像以可驾驶的立体地形呈现内容。作者披露 Three.js、Rapier、Howler.js，并说明 WebGPU 渲染选项。
- **取舍与原创改造** · 小行星让地标反馈出现在玩家到达时，保留易找到的暂停、重开和退出入口。用俯视图、点选目的地和小地图边界取代驾驶、车辆模型和物理。实现复杂度中高，与 Messenger 的改造共用同一个二维探索小站。

[官方网站与制作说明](https://bruno-simon.com/)

## The Tie-break

- **作品与流程** · Merci-Michel 的互动作品。公开评奖页确认以可玩体验引出 Coco Gauff 参与展示的联名系列。官网正文无法通过公开网页读取，计分规则、输入细节和结算画面没有核实。
- **视觉与技术** · 可确认的是网球主题与时装叙事的结合。动态视觉、配色和技术栈的细节未在可核实的来源中完整披露。
- **取舍与原创改造** · 采用「一局结束后才交付回顾」的通用机制，给小行星设计星数、时间和秘密状态，给形状实验室设计作品反馈与回看。联名内容、比赛规则和营销跳转不进入项目。实现复杂度低至中等，主要是结果状态和保存反馈。

[官方网站](https://thetiebreak.merci-michel.com/) · [Global Web Design Awards 作品页](https://globalwebdesignawards.com/sites/the-tie-break)

## 落地原则

四个入口的操作动词分别是「画」「走」「读」「摆」。每个小站完成一次明确的反馈循环，并能随时退出。复用无聊宇宙的原创 WebP、色彩、字体和聊绒，新增画面由本项目的 CSS 和 Canvas 组合。对比这些案例时采用的是机制和节奏，未使用其角色、源码、音乐或图像。
