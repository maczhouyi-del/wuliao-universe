# 随机玩意开发与测试报告

本文记录引入混合随机池时的历史版本。现行玩法和目录以 [README](../README.md) 和 [扩容核验记录](external-sites-research.md) 为准。

## 用户流程

「随机玩意」统一承接原创体验和奇妙互联网。进入 `/random` 会抽取一张卡片，也可以用「全部体验」「本站小游戏」「奇妙互联网」或原有原创分类缩小范围。点「再来一个奇怪的东西」会在当前页面切换结果。

原创卡片沿用游戏操作、分享和收藏。外站卡片展示原站名称、简介、分类、标签、来源及设备建议。用户主动点「进入原网站」才会在当前标签页前往原站。浏览器返回能恢复原卡片及筛选。我的档案新增「收藏的外部网站」和「最近遇到的网站」，两处均可直接打开原站。

## 路由、抽取和存档

| 项目 | 实现 |
| --- | --- |
| 旧地址 | `/collection` 通过 `history.replaceState` 转到 `/random`。旧 `type` 可转换为原创分类，旧 `section=internet` 可转换为外站筛选。 |
| 结果地址 | 原创卡片用 `id`，外站卡片用 `site`，筛选用 `type`。刷新、前进和返回时从地址恢复。当指定条目不存在或外站未发布时，会从当前筛选重新抽取。原有隐藏原创深链接仍可展示解锁提示。 |
| 内容类型 | `experiences` 仍由原创游戏使用，外站单独取自 `external-sites.js`。统一抽取结果通过 `kind` 和 `id` 标记类型。 |
| 混合比例 | 两类都有可换条目时，外站概率默认 25%，可在 `random-explore.js` 调整。指定筛选时只抽该筛选内的内容。 |
| 重复与空状态 | 抽取排除当前结果，同类型内优先此前未遇到的条目，必要时再从较早遇到的条目中选择。筛选内只有当前这一项时保留卡片并给出提示，空池保留筛选控件。 |
| 原创存档 | 继续使用 `wuliao-universe-v1`。保留收藏、成绩、发现和念头罐。原创 `visited` 可记住全部已遇到的有效原创条目，现有历史保留。 |
| 外站存档 | `externalFavorites` 保存网站收藏，`externalVisited` 保存最近 12 个不重复的遇见或访问记录，`externalSeen` 用于优先推荐此前未遇到的网站。已知但暂时下线的网站收藏仍可保留，恢复发布后可再次展示。 |

## 文件分工

- `public/app.js` 接入抽取、路由兼容、搜索、站内切换、档案和收藏。`public/index.html` 移除旧导航，`public/content.js` 更新原任务的文本和链接，保留任务索引。
- `public/random-explore.js` 管理筛选、地址解析、抽取概率和去重。`public/external-sites.js` 保留独立目录并校验发布状态和 HTTPS 地址。
- `public/external-card.js` 复用自制 SVG 绘制单张外站卡片，`public/style.css` 提供卡片布局、切换反馈和窄屏样式。
- `public/state.js` 校验浏览器存档并记录外站收藏和历史，`tests/external-sites.test.js` 覆盖目录、抽取、路由、存档及外站卡片。

## 核验和测试

- 重新核验了 6 个原站的 HTTPS 地址和页面。The Tie-break 的同源语言页可进入对阵引导，Messenger 的场景可以加载。详细原站、来源和状态见[链接维护记录](external-sites.md)。
- `npm run check` 与 `npm test` 通过，共 19 项自动化测试。Chromium 的原功能回归覆盖 17 个原创体验入口，以及设置、搜索、进度、旧存档和任务分享。
- Chromium、Firefox 和 WebKit 验证了混合抽取、三种筛选、刷新恢复、外站收藏与历史、旧地址兼容和窄屏布局。Chromium 还验证了全为 `pending` 时的空状态，以及 Why Zero 和 Ponpon Mania 在同一标签页打开并返回原卡片。
- Chromium 检查了 320、375、390、430 像素宽度和模拟触屏，Firefox 与 WebKit 检查了 320 和 390 像素宽度。检查中未发现横向溢出。新卡片桌面与 320 像素下的 axe 扫描在所测 WCAG A/AA 规则中无报告。

移动端流程使用模拟触屏。外站核验覆盖入口和关键导航，未逐一通关第三方互动作品。
